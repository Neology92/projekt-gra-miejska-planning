# Z1 Navigation Maps

10 print-ready maps (A4 landscape) for the Z1 "szlak symboli" puzzle.
Each map shows 9 geometric pin markers at real Toruń locations.

## Files

| File | Purpose |
|------|---------|
| `z1-map-data.js` | All coordinates, glyph SVGs, group definitions |
| `z1-map.html` | Print view (`?view=G1..G10 &style=clean|parchment`) |
| `z1-map-tune.html` | Interactive calibration — set `FROZEN_CENTER`/`FROZEN_ZOOM` |
| `z1-map.css` | Layout, pin styles, parchment toggle |
| `z1-gm-key.html` | GM reference: code → glyph → place |
| `render-map.ps1` | Headless Chrome batch renderer |
| `output/` | PNG + PDF output (generated by render script) |

## Requirements

- **Network required** for render: Leaflet 1.9.4 (CDN) + CARTO `light_nolabels` tiles.
- Chrome or Edge (auto-detected by render script).
- PowerShell 7+ (`pwsh`).

## Workflow

### 1 — Calibrate the frozen view

Open `z1-map-tune.html` in Chrome. Pan and zoom until all 19 pins fit with ~5% margin.

Tips:
- Keep zoom near an integer (e.g. `15` not `14.7`) — fractional zoom causes CARTO to scale tiles from a lower level, reducing sharpness.
- The red dashed rectangle shows the Rynek cluster (rendered in inset only).
- Aim for `FROZEN_ZOOM` between 15 and 16 — higher = sharper tiles but tighter frame.

Copy the `center` and `zoom` values from the readout panel, then paste into `z1-map-data.js`:

```js
const FROZEN_CENTER = [lat, lng];   // from tune readout
const FROZEN_ZOOM   = zoom;         // near-integer, e.g. 15 or 16
```

### 2 — Test render (single group)

```powershell
pwsh -File render-map.ps1 -Group G1
```

Open `output/z1-map-G1.png` at **100% zoom** and check:
- Building edges are sharp (not pixelated)
- Exactly 9 pin markers visible on main map + inset
- Rynek cluster pins are separated in the inset box

Open `output/z1-map-G1.pdf` at **300%** — raster should not be blurry.

### 3 — Aesthetics comparison

```powershell
pwsh -File render-map.ps1 -Compare
```

Renders `G1-clean.png` and `G1-parchment.png` for side-by-side comparison.
Decide which style to use for the full run.

### 4 — Full render (10 groups)

```powershell
pwsh -File render-map.ps1 -Style clean    # or: -Style parchment
```

### 5 — Determinism check

Overlay `z1-map-G1.png` and `z1-map-G8.png` in an image editor — both contain `N01`.
The pin should land at the **identical pixel** on both maps.

### 6 — Spot-check group codes

Each map's 9 codes should match the group table in `z1-map-data.js`:

```
G1:  N01 N02 N06 C04 | N04 N05 N03 S04 W01
G2:  N06 N04 N05 C01 | N01 C02 C06 S01 W01
...
```

## Troubleshooting

**Grey/empty map (tiles not loaded)**  
CARTO timed out. Re-run `render-map.ps1` — tiles are usually cached on second attempt.
If persistent, check network connectivity.

**Pins sharp but map tiles blurry**  
The real dpi lever is `FROZEN_ZOOM`, not `--force-device-scale-factor`.
Increase `FROZEN_ZOOM` by 0.5–1 and re-tune the frame in `tune.html`.
Keep zoom near an integer.

**PDF render fails / PDF very small**  
PNG → PDF wrapper path may have spaces. Try running from a path without spaces,
or copy the HTML to `C:\Temp\` and adjust the script path.

**Inset pins overlapping**  
`Z1_INSET_BOUNDS` in `z1-map-data.js` controls the inset zoom. Expand the bounds
(move SW more south/west, NE more north/east) to zoom out the inset.
